# Pressure Scenarios

## Scenario

Canonical skills coexist with empty mirrors, mixed built-in mirrors, stale
links, cross-scope links, and divergent copies.

## Required evidence

Full classification, agent discovery requirement, same-scope resolution, and
conflict-preserving migration plan.

## Pass criteria

Empty dedicated mirrors become directory links, mixed mirrors receive
per-skill links, and no real or divergent content is overwritten.
