# Brainstorming

Use this skill when starting creative or implementation work that needs exploration of user intent, requirements, constraints, or design options before coding.

## Guidance

- Confirm the trigger matches the current task before applying this workflow.
- Use the `grill-me` skill for genuine discovery — material ambiguity in intent, requirements, or constraints — or when the user explicitly requests an interview. Skip it when context is already sufficient; do not manufacture another interview round.
- Keep the work scoped to the named capability and prefer narrower repo-local overrides when present.
- Preserve relevant evidence, commands, paths, and validation results in the final handoff.
- Update this skill with more specific guidance when a repeatable failure mode or workflow detail emerges.
